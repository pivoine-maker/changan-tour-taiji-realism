# 固定鸟瞰全局地图模式设计

## 目标

- 将当前可旋转、可拉到地面的三维漫游视角改为单一鸟瞰地图视角。
- 地名不再作为可开关悬浮标签，而是默认铺在地图对应位置，形成历史总图阅读体验。
- 保留缩放、拖拽平移、点击行走、任务与 NPC/宝物/考古点标记。

## 交互

- 页面默认进入鸟瞰全局地图。
- 鼠标拖拽只用于平移地图，不再旋转视角。
- 鼠标滚轮和 `+ / -` 只改变地图缩放，不再进入贴地视角。
- “找到旅人”和“找到 NPC”改为在鸟瞰地图中居中目标，不切换低角度镜头。
- “重置视角”回到全城鸟瞰中心。
- 移除顶部“显示地名 / 隐藏地名”开关，地名默认常驻。

## 视觉

- 镜头保持从正上方俯视，北向固定，不允许倾斜旋转。
- 地名采用地图印字风格：更轻的半透明底、更少胶囊感、更像印在地图上的文字。
- 全景优先显示主要区域和道路；放大后显示坊区、NPC、宝物与考古点。
- 任务面板继续在右侧，不遮挡地图主体。

## 验收

- 初始化、重置、找到旅人、找到 NPC 后都保持鸟瞰视角。
- 拖拽不会旋转地图，只会平移。
- 缩放范围不会进入地面视角。
- 地名默认显示，不需要点击开关。
- 顶部不再出现“显示地名 / 隐藏地名”按钮。
- 现有任务、NPC、宝物、考古发现功能不被破坏。
