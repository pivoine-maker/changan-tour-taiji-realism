# 浅池结构与静态反射

保留原内园水域、池框和十字园路的 XZ 范围。原水面高于池框且覆盖园路；新水面 y=0.335，池底顶面0.315，园路底面0.345、顶面0.405，池沿常规顶面0.405，穿路处降至0.345。四块地面避开外池框，园路用三个互不重叠的矩形拼出原并集，延续世界坐标纹理相位。

这是2cm的浅水结构修正，不宣称真实深水模拟。水使用不透明深色物理材质，256px静态立方体反射仅初始化一次，捕获点避开跨池园路，隐藏水面与旅人。独立反射失败应回退已有HDR；捕获不能污染主相机LOD/冻结阴影。自有RT幂等释放，不释放借用材质。

视觉验收：同机位旧水像盖在路上的蓝板；候选园路和池水关系清楚，保留。高视角水仍偏平色，低视角有有限反射，不继续颜色微调，不认定照片感已完成。实际静观和开关验证需在修复探针副作用后重做，800万顶点内存上限不变。
