# 写实模式发现位置提示

问题：18个发现点使用半径1.6m、悬浮y4.4的实心八面体，投影与反射让它们像建筑实体，明显破坏场景尺度。它们仅作视觉提示，发现仍由旅人进入原有位置/半径触发，不直接点击mesh。

候选：仅写实模式把旧八面体替换为18px屏幕叠加的空心金色位置图标，已发现用实心/勾号区分。默认显示，不为了截图自动隐藏。图标可穿透遮挡，明确属于导航界面，类似现有地名标签；不伪造历史建筑。图标不拦截鼠标，原地面点击寻路与发现数据不变。出视口/相机后方不显示。地名显示开关继续控制文字地名，不改变其现有含义。

原始模式恢复原八面体的可见性与发现着色；销毁恢复并移除自有DOM，无共享几何材质释放。静观也继续显示位置图标。候选先看实际默认/池塘同机位图，再决定保留，不声称此改动能使全场景达到照片感。
