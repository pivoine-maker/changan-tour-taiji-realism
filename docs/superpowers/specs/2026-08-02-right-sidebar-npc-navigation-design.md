# 右侧任务标签与 NPC 循环定位设计

## 目标

- 将寻宝任务面板从沙盘左侧移入右侧栏，释放城市视野。
- 在右侧栏用“寻宝任务 / 考古发现”双标签切换两类内容。
- 顶部新增“找到 NPC”按钮，每次点击循环定位到下一位 NPC。

## 交互

- 右侧栏默认打开“寻宝任务”。
- 点击“考古发现”显示原有发现列表与档案；打开发现记录时自动切到该标签。
- “找到 NPC”按数据顺序循环：西市胡商 → 坊门里正 → 瓦作工匠 → 朱雀街巡吏 → 宫城内侍 → 回到胡商。
- 定位只切换镜头，不瞬移旅人，也不提前推进任务。
- 被定位的 NPC 临时显示标记；当前任务目标标记继续保留。

## 视觉

- 任务面板使用右栏完整宽度并允许滚动，不再使用覆盖沙盘的绝对定位卡片。
- 双标签沿用现有深色考古档案风格。
- NPC 镜头采用低角度近景，便于识别人形标记和周边街区。

## 验收

- 沙盘内部不存在 `.quest-panel`。
- 右栏包含两个可切换标签。
- 顶部存在“找到 NPC”按钮并绑定回调。
- 连续点击会按五位 NPC 顺序循环。
- 现有任务、考古发现、WASD、找到旅人和缩放不受影响。
