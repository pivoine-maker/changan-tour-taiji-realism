# Secondary roof cover tile candidate

Full-building noncrafted roofs now use a shared low-cost hollow half-round cover shell instead of solid octagonal cylinders. The indexed 48-vertex unit tile has an open underside, thin shell, slight downstream flare, and a forward-facing molded rim. Its local Z axis follows each existing roof run and its crown follows projected world up, seated .02 m above the roof surface.

Tile runs, row and column counts, tone variation, materials, roof underlay, shadows, and XZ footprints are unchanged. Crafted main-hall tiles and narrow wall-cap cylinders remain unchanged.
