# XIII stone PBR evaluation

Evaluate Poly Haven Rock 01, an authored CC0 stone surface by Rob Tuytel, using its diffuse, OpenGL normal and roughness maps. The source does not certify limestone or a photographic creation method. Use it only for exposed stone structures and paving, leaving plaster on its existing material. Keep normal strength restrained to suit cut stone. No light, exposure, layout or interaction changes.

The acceptance criterion is an improvement in surface response and overall reference comparison, not merely extra noise or more tests. Capture identical timber and whole-scene views from XII and the candidate. Reject or revise a candidate that looks excessively rocky, dark or repetitive. Preserve XII unchanged.

## Result
Rejected: complete map set made broad paving too dark and too reflective relative to the approved pale dry stone. Runtime and tests restored to XII, original source files and candidate screenshots retained offline. No XIII release.
