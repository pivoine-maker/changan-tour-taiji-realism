# 长安全域地名覆盖层设计

## 目标

- 为全城沙盘增加可开关的半透明地名覆盖层，帮助玩家辨认公元 750 年长安的空间结构。
- 覆盖城区、坊区、道路、城门、宫殿、NPC、宝物和考古发现点。
- 保持沙盘点击行走、镜头旋转、缩放、任务触发等现有交互不受影响。

## 入口与状态

- 顶部操作区新增“显示地名”按钮。
- 地名层默认关闭；点击后开启并将按钮文案改为“隐藏地名”，再次点击关闭。
- 按钮使用 `aria-pressed` 暴露当前状态。
- 地名状态只在当前页面会话内保持，不写入任务或考古进度。

## 标注内容

- **城区 / 坊区**：西市、各普通坊区、皇城与宫城片区。
- **道路**：朱雀大街和宫城中轴等主要道路。
- **城门 / 宫殿**：西市门、朱雀门、承天门、太极殿、内廷园林等。
- **NPC**：阿罗罕、裴里正、鲁六郎、韩旅帅、高内谒。
- **宝物**：四章任务对应的通关牒、坊门钥牌、巡符与仪仗牌。
- **考古点**：现有十个发现点，沿用发现数据中的正式名称。

## 视觉层级

- 使用 HTML 屏幕空间投影标注，始终朝向屏幕并保持中文清晰。
- 标注是半透明铭牌，带轻微描边和阴影，容器不接收鼠标事件。
- 分级配色：城区和坊区为暗褐色，宫殿与城门为金色，道路为米白色，NPC 为青色，宝物为琥珀色，考古点为朱红色。
- 每类标注使用不同前缀图形，方便在密集区域快速区分。

## 密度与可见性

- 城区、坊区、道路与大型地标在全景和中景可见。
- NPC、宝物、考古点仅在中近景显示，减少全城俯视时的文字堆叠。
- 屏幕外、镜头背后以及超出当前密度阈值的标注隐藏。
- 同类型标签发生明显重叠时，优先保留重要级别更高的标签。
- 投影位置跟随镜头每帧更新，不改变 Three.js 场景物体。

## 数据与架构

- 新建统一的地图标签数据结构，包含 `id`、`label`、`kind`、世界坐标、高度、重要级别和显示距离。
- 标签从 `westMarketWorld` 的坊区、道路、宫城数据，以及任务、发现数据派生，避免维护重复坐标。
- `WestMarketScene` 创建并管理覆盖层 DOM、切换状态和每帧投影。
- `appUi` 只负责顶部按钮和回调；`main` 负责把按钮接到场景开关。

## 验收

- 顶部存在“显示地名”按钮，点击后变为“隐藏地名”。
- 开启后能看到分级配色的城区、道路、宫殿、NPC、宝物和考古点名称。
- 拉远时自动减少细节标签，拉近后显示 NPC、宝物与考古点。
- 标签不会挡住沙盘鼠标交互，也不会推进任务或改变旅人位置。
- 关闭后覆盖层完全隐藏，现有功能与性能无明显回退。
