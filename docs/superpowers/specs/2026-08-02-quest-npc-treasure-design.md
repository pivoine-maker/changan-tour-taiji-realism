# 长安寻宝关卡与 NPC 互动设计

## 目标

把当前“点击行走 + 考古发现”的沙盘体验，升级为有章节目标、线索背包、NPC 对话和历史知识卡的可玩寻宝游戏闭环。

## 第一版范围

- 保留现有 10 个考古发现与档案面板。
- 新增 4 章主线关卡，每章有 2–3 个目标点。
- 新增 4 件关键线索物，收集后解锁下一章。
- 新增 5 个 NPC，玩家靠近后自动弹出对话提示与任务推进。
- 新增任务面板、线索背包、NPC 对话浮层和知识卡区域。
- 不新增复杂战斗、背包拖拽、经济系统或支线任务。

## 章节线

1. **入市寻牒**：西市西门 → 胡商旅舍 → 市署，获得“通关牒”。
2. **坊门夜禁**：普通坊区 → 坊门 → 里坊水井，获得“坊门钥牌”。
3. **朱雀中轴**：朱雀大街 → 巡吏 → 承天门，获得“朱雀街巡符”。
4. **宫城礼仪**：皇城官署 → 太极殿 → 内廷园林，获得“宫城仪仗牌”。

## NPC

- **西市胡商**：讲丝路贸易、货签、商旅身份。
- **坊门里正**：讲坊墙、夜禁、里坊生活秩序。
- **朱雀街巡吏**：讲中轴道路、礼制交通与通行管理。
- **瓦作工匠**：讲唐代屋顶、檐口与木构复原。
- **宫城内侍**：讲承天门、太极宫与朝会礼仪。

## 历史知识卡

每个 NPC 对话解锁一张知识卡，结构沿用当前考古档案的信息伦理：

- 史料确认：已由文献或考古支持的事实。
- 复原推测：游戏为了空间体验做出的表达。
- 尚不确定：明确提示玩家不要把模型视为精确复原。

## 交互规则

- 旅人靠近 NPC 或宝物点时触发交互，不需要额外按键。
- 每个章节只显示当前目标，减少玩家迷路。
- 完成当前章节所有目标后自动进入下一章。
- 清除记录会同时清除考古发现、任务进度、线索和知识卡。
- 3D 场景中用不同标记区分 NPC 与宝物：NPC 为人形小标，宝物为发光线索牌。

## 技术方案

- 新建 `src/data/quests.ts` 存放章节、目标、NPC、宝物和知识卡数据。
- 新建 `src/quests/state.ts` 管理持久化任务进度。
- 场景层新增可交互实体标记，并复用每帧位置检测触发交互。
- UI 层新增任务面板与对话/知识卡渲染方法。
- 测试覆盖数据完整性、状态机推进、UI 渲染和场景实体创建。

## 验收标准

- 页面可看到“当前任务”和“线索背包”。
- 靠近 NPC 会显示对话并解锁知识卡。
- 靠近宝物会加入线索背包并推进章节。
- 完成 4 章后显示“长安寻宝完成”。
- 现有考古发现、WASD、缩放、找到旅人功能保持可用。
- 测试和生产构建通过，浏览器控制台无错误。
