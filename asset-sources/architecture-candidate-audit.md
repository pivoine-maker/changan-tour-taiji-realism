# Architecture candidate audit — 2026-09-09

These models were researched, not imported. No viewer asset extraction or authentication bypass was used.

- [Temple — Vincerew](https://sketchfab.com/3d-models/temple-e28da4013d554cb7b1fb6bc46cb71615): public API lists downloadable, CC BY 4.0, 60,280 triangles. Author describes a simplified Nanchan / Tang–Song reference model. No anonymous official binary link established. Potential component donor, not a scanned palace.
- [Dougong with animation — Crawford96](https://sketchfab.com/3d-models/dougong-with-animation-56379b6e72564875b84a89f8857c7b35): public API license CC BY-NC-SA 4.0, 77,412 triangles. [Zenodo archive](https://zenodo.org/records/10237644) has a public 3.4 MB GLB. Not incorporated, because the noncommercial/share-alike terms are unsuitable as a default dependency for a broadly reusable game scene.
- [Kneeling Winged Monster — Smithsonian](https://sketchfab.com/3d-models/kneeling-winged-monster-2f47456dee4f4ad7a0f1468e7ee2d24e): CC0, 150k triangles, Northern Qi pillar support from Buddhist cave context. Official download unavailable in this environment; also wrong architectural context for an unqualified Taiji Palace addition.

XII bracket and beam meshes are self-authored from geometric primitives and profiles. No mesh from these candidates was copied. Their artistic form should not be described as a measured historical reconstruction.
